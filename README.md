# 智医助手・镇痛类药物辅助决策系统 

## 一、项目概述

"智医助手"是一款面向临床医护人员的 AI 驱动型临床决策支持系统（CDSS），专注于镇痛类药物（尤其是阿片类药物）的处方辅助决策。系统整合了循证医学知识库、风险评估模型、合规审查引擎与大语言模型（LLM）能力，为医生在急性疼痛、慢性疼痛、癌性疼痛及药物成瘾治疗等临床场景中提供智能化、规范化的用药建议。

### 核心定位

- **目标用户**：临床医生、药剂师、护理人员等医疗专业人员
- **应用场景**：阿片类药物处方管理、疼痛评估与分级、成瘾风险筛查、政策合规审查
- **核心价值**：降低阿片类药物滥用风险，提升处方合理性，辅助临床培训

## 二、系统架构

### 2.1 技术栈

| 层级 | 技术选型 | 说明 |
|------|---------|------|
| 前端（主） | Next.js 14 + React 18 + TypeScript | 生产级现代化前端 |
| 前端（辅） | Streamlit 1.35 | 快速原型迭代界面 |
| 样式系统 | Tailwind CSS 3.4 | 响应式设计，支持暗色模式 |
| 后端 API | FastAPI 0.115 + Uvicorn | 高性能异步 API 服务 |
| 认证鉴权 | JWT (python-jose) + bcrypt | Token 认证 + 密码哈希 |
| 数据校验 | Pydantic 2.10 | 强类型数据模型 |
| LLM 集成 | OpenAI SDK 1.30 / DashScope | 多模型供应商支持 |
| 数据库 | PostgreSQL (psycopg 3.2) | 关系型数据持久化 |

### 2.2 架构模式

系统采用前后端分离 + 分层架构设计：

```
用户界面层 (Next.js / Streamlit)
    ↓
API 网关层 (FastAPI + JWT 鉴权)
    ↓
业务服务层 (clinical_service / llm_service / metrics_service / followup_service)
    ↓
数据访问层 (content_repository / session_repository)
    ↓
知识库 & 数据层 (临床病例库 / 专家共识 / 政策法规库 / PostgreSQL)
```

**数据流转**：用户输入患者信息 → 临床服务计算风险评分（ORT） → 病例库检索相似案例 → LLM 生成个性化建议 → 规则引擎执行合规审查 → 返回带循证引用的推荐方案

## 三、功能模块详解

### 3.1 临床辅助决策（核心模块）

系统的核心功能模块，为医生提供实时的用药决策支持：

- **患者信息录入**：结构化病例输入表单，支持疼痛评分、既往病史、用药史等关键信息采集
- **ORT 风险分层评估**：基于阿片类药物风险评估工具（Opioid Risk Tool）自动计算患者成瘾风险等级，分为低危/中危/高危三级
- **智能处方推荐**：结合患者病情、风险等级与临床指南，生成个性化的镇痛药物方案，包含药物选择、剂量、给药途径与疗程建议
- **合规红线预警**：实时检测处方是否违反相关法规政策，对超剂量、禁忌联用、高风险处方等情况发出警示
- **MME 换算**：内置吗啡毫克当量（Morphine Milligram Equivalents）换算因子，辅助医生评估阿片类药物总暴露量

### 3.2 虚拟培训系统

面向医护人员的 AI 驱动临床培训平台：

- **海量标准化患者**：基于 AI 生成的 50,000+ 虚拟病例场景，覆盖多种疼痛与成瘾治疗情境
- **多轮交互问诊**：模拟真实临床问诊流程，支持病史采集、体格检查、辅助检查等多轮对话
- **智能评分反馈**：对学员的诊疗过程进行自动评分，从问诊完整性、诊断准确性、处方合理性等维度给出量化评价
- **心理画像分析**：识别学员的临床决策风格（恐惧回避型/开放探索型/依赖咨询型），提供针对性改进建议
- **培训记录追踪**：完整记录每次培训的过程与成绩，支持学习进度可视化

### 3.3 政策法规库

镇痛类药物相关政策法规的智能检索与合规辅助：

- **政策全文检索**：支持关键词搜索国家及地方性镇痛药物管理法规
- **合规性校验**：将处方方案与现行法规自动比对，识别潜在合规风险
- **地区差异化**：支持省级行政区划的政策差异查询，适应不同地区的监管要求
- **医保覆盖规则**：集成医保目录信息，标注药物的医保报销类别与限制条件
- **政策问答**：基于 LLM 的自然语言问答，快速解答法规相关疑问

### 3.4 医生工作台（Dashboard）

面向科室管理者的数据看板与患者管理工具：

- **患者风险分布**：可视化展示在管患者的风险等级分布
- **治疗状态监控**：追踪患者的治疗进展、用药依从性与随访状态
- **不良事件追踪**：记录与统计药物不良反应事件，支持上报与分析
- **数据分析报表**：生成科室用药统计、处方合理性分析等管理报表
- **新闻与动态**：推送镇痛领域最新临床研究、指南更新与政策变动

### 3.5 个人中心

用户账户与偏好管理：

- **账户管理**：登录注册、密码修改、角色权限查看
- **培训档案**：个人培训历史与成绩汇总
- **偏好设置**：界面主题、通知偏好等个性化配置

## 四、知识库体系

系统的决策能力建立在两大专业知识库之上：

### 4.1 阿片类药物临床知识库（medical-opioid）

- **数据来源**：2024 年专家共识与临床指南
- **病例规模**：118 例真实临床案例
- **覆盖病种**：
  - 急性重症疼痛：急性冠脉综合征（ACS）、主动脉夹层、重症胰腺炎、创伤性脑损伤、烧伤、机械通气
  - 癌性疼痛与术后疼痛管理
  - 阿片类药物相关并发症处理
- **知识结构**：每条病例包含诊断信息、推荐方案、循证等级、风险提示与预期结局
- **检索机制**：两步式工作流——先检索相似病例，再检索对应指南条文，最终整合输出

### 4.2 成瘾治疗知识库（addiction-treatment）

- **病例规模**：5,000+ 真实成瘾治疗案例
- **覆盖类型**：阿片类成瘾、酒精成瘾、甲基苯丙胺成瘾
- **治疗药物**：丁丙诺啡（Buprenorphine）、美沙酮（Methadone）、纳曲酮（Naltrexone）
- **决策维度**：基于患者年龄、成瘾类型、严重程度的个性化用药推荐，涵盖剂量、频次、疗程分组
- **安全机制**：禁忌症标注、戒断症状管理方案、用药依从性监测指标

## 五、UI/UX 设计

### 5.1 视觉风格

- **设计语言**：现代简洁风，融合玻璃拟态（Glassmorphism）效果
- **主色调**：深紫色（#5400db）+ 青色点缀（#00f2ff），传达科技感与专业感
- **辅助色**：翡翠绿（成功）、琥珀色（警告）、红色（危险）、蓝色（信息）
- **字体**：Inter 无衬线字体，搭配 Material Symbols Outlined 图标库
- **圆角风格**：大圆角（2xl/3xl），营造柔和友好的视觉体验

### 5.2 交互特性

- **响应式布局**：移动端优先设计，适配桌面与平板设备
- **暗色模式**：基于 CSS class 切换的深色主题支持
- **平滑过渡**：悬停状态、页面切换均配有流畅动画
- **自定义滚动条**：统一的滚动条样式，保持视觉一致性

### 5.3 品牌标识

- **系统名称**：智医助手（ZhiYi Assistant）
- **Logo**：圆形徽章式设计，以晶体盾牌为主体，融合医疗十字、向上箭头与药物胶囊元素，外围环绕科技光轨粒子，整体呈现深蓝紫色调的未来医疗风格

## 六、安全与合规

### 6.1 身份认证

- JWT（JSON Web Token）无状态认证机制
- bcrypt 密码哈希存储，防止明文泄露
- 会话状态管理与自动过期

### 6.2 访问控制

- 基于角色的访问控制（RBAC），区分医生、管理员等角色权限
- 受保护页面路由守卫，未认证用户自动重定向至登录页
- CORS 中间件配置，防止跨域攻击

### 6.3 临床合规

- 处方红线规则引擎，自动拦截违规处方
- 阿片类药物 MME 总量监控
- 操作日志记录，支持审计追溯
